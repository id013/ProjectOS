# Starter Pack: Website & SEO

Use this pack for a website redesign, SEO architecture, service-page system, editorial program, or controlled no-code implementation.

## Required inputs

- current URL and content inventory;
- approved product, service, brand, and legal facts;
- analytics and search data where available;
- target audiences and conversion actions;
- platform constraints and access level.

## Workflow

1. baseline audit;
2. customer, search-intent, and competitor evidence;
3. information architecture and redirect plan;
4. message and design system;
5. one service-page pilot;
6. one editorial-page pilot;
7. batch production with manifests;
8. technical, content, UX, and release QA.

## Gates

- **Evidence Gate:** architecture and claims trace to sources or dated assumptions.
- **Template Gate:** pilots pass before batch production.
- **Batch Gate:** repeated failures stop the batch.
- **Publication Gate:** URLs, redirects, metadata, links, forms, analytics, mobile layout, accessibility, and rollback are verified.

## Initialization prompt

```text
Initialize the Website & SEO starter pack in Standard mode.
First audit the available sources and current site. Do not redesign or publish yet.
Create the charter, URL inventory requirements, Source of Truth Register,
workstreams, risks, pilot plan, quality gates, and measurable Definition of Done.
Anonymize client information in any public artifact.
```
