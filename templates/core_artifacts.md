# Основные Markdown-шаблоны

Используйте только нужные уровню проекта разделы. Поля с `*` обязательны; для Lite допустимо объединить Charter, DNA и Status в одном файле, а журналы — в одной таблице.

## A. Project Charter

```markdown
---
artifact_id: CHR-001
version: 0.1
status: Draft
owner: [имя/роль]
updated: YYYY-MM-DD
data_class: Internal
---
# Project Charter — [название]*
## Цель* / бизнес-результат*
[измеримый результат и для кого]
## Проблема и исходное состояние*
## Границы*
- Включено:
- Не включено:
## Заинтересованные лица и полномочия*
| Роль | Лицо | Решает | Информируется |
## Ограничения / ресурсы / зависимости
## Критические риски
## Критерии успеха*
| ID | Метрика/наблюдение | Цель | Как проверяется | Владелец |
## Критерии остановки*
## Текущий статус и ближайший Gate*
## Источники / допущения / связанные артефакты
```
