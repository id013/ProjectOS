# ProjectOS Reference

## Modes

- Lite: short, low-risk, one deliverable.
- Standard: multi-step work with several inputs or outputs.
- Advanced: public, sensitive, expensive, regulated, or batch work.
- Program: several projects sharing sources and decisions.

## Required artifacts

Standard and higher modes use:

- Project Charter;
- Source of Truth Register;
- Decision Log;
- Assumption and Risk Register;
- workflow cards;
- Context Manifest;
- Quality Gate;
- Handoff Pack;
- Change Log.

## Invariants

1. Approved sources override conversation memory.
2. Unverified facts stay labeled.
3. Approved artifacts are not silently overwritten.
4. Source changes trigger dependent review.
5. Material outputs receive independent review.
6. Consequential actions require explicit approval.
7. Completion requires evidence.

## Batch sequence

Inventory, normalize, segment, template, pilot, gate, batch, automated checks, risk-based sampling, release.

## Handoff test

The receiving agent must be able to restate the outcome, constraints, sources, risks, status, and exact next action without access to the original conversation.
