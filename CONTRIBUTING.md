# Как внести вклад

Project OS принимает изменения, которые делают процесс проверяемее, переносимее или проще без ослабления безопасности.

1. Создайте issue с проблемой, примером и ожидаемым результатом.
2. Для новой методологии приложите минимум один проверяемый сценарий применения.
3. Не меняйте смысл Approved-правил без записи причины, риска и rollback в changelog.
4. Сохраняйте ядро независимым от конкретного продукта; платформенные детали помещайте в адаптер.
5. Проверьте внутренние ссылки, code fences, лицензии и отсутствие секретов.
6. Опишите изменение и способ проверки в pull request.

Внешние skills принимаются только с зафиксированными происхождением, версией, лицензией и ограничениями.
