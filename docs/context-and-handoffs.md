# Context and Handoffs

More context is not automatically better. Supply the smallest context that lets an agent make correct decisions for one outcome.

## Context Manifest

A session receives:

- desired outcome;
- Definition of Done;
- current stage;
- authoritative sources;
- relevant decisions and assumptions;
- constraints and permissions;
- required output format;
- known risks;
- next expected handoff.

Avoid attaching the full archive unless the task is explicitly an audit of the full archive.

## Source hierarchy

1. approved primary sources;
2. approved project artifacts;
3. current official external sources;
4. dated research notes;
5. assumptions;
6. conversation history.

When sources conflict, stop propagation, record the conflict, identify the owner, and resolve or explicitly carry the uncertainty.

## Portable Handoff Pack

A handoff contains:

1. goal and current status;
2. approved Project DNA;
3. Source of Truth Register;
4. active decisions, assumptions, and risks;
5. current workflow card and Context Manifest;
6. approved deliverables and necessary sources;
7. quality standard and open findings;
8. exact next action;
9. file manifest and data classification.

Before resuming work in a new environment, ask the receiving agent to restate the outcome, constraints, sources, risks, and next action. Run a small trial before continuing a critical stage.
