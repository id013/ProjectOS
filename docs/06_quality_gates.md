# Многоступенчатый Quality Gate

## Универсальный Gate

| Шаг | Проверка | Доказательство прохождения |
|---|---|---|
| Q1 | соответствие цели и области | матрица критерий -> фрагмент результата |
| Q2 | полнота | нет незаявленных пропусков; пробелы перечислены |
| Q3 | факты и источники | первичные источники, даты, границы уверенности |
| Q4 | непротиворечивость | сверка SoT, конфликтов и зависимостей |
| Q5 | Project DNA | запреты, стиль, технические ограничения соблюдены |
| Q6 | терминология | Glossary соблюден, новые термины предложены отдельно |
| Q7 | риски | failure modes и остаточный риск зафиксированы |
| Q8 | пригодность | формат открывается, инструкции исполнимы, ссылки работают |
| Q9 | человеческая проверка | обязательна для критических решений |
| Q10 | фиксация | версия, статус, владелец, changelog и реестры обновлены |

Для публичных, редакционных и коммерческих текстов после Q6 применяется [Editorial Humanization Gate](19_editorial_humanization_gate.md). Он проверяет голос, рекламную воду и шаблонные AI-обороты, но не может менять подтвержденные факты. Для операционных инструкций дополнительно проверяется [Focus Mode](20_focus_mode.md): действие должно быть видно без потери обязательного контекста.

## Разделение ролей

Для Lite допускается два прохода одной моделью с явным переключением роли и чистым контекстом. Для Standard важный результат проверяется отдельной Work-задачей Critic/QA. Для Advanced/Program факты и финальное принятие проверяют независимо; финальный человек не должен опираться только на резюме производителя.

## Вердикты

- `PASS`: все обязательные критерии выполнены.
- `PASS WITH ACCEPTED RISK`: дефекты не блокируют использование, риск имеет владельца и срок.
- `REWORK`: исправимый C1/C2.
- `BLOCK`: C3, отсутствует критический источник/полномочие или результат небезопасен.

## Минимальный QA Report

```markdown
# QA Report — [артефакт, версия]
- Проверяющий / роль:
- Дата и срез источников:
- Примененный чек-лист:
- Вердикт:
- C3/C2/C1/C0 находки:
- Проверенные утверждения и источники:
- Непроверенные области:
- Остаточные риски и владельцы:
- Требуемые исправления:
- Повторная проверка:
```

Предметные проверки приведены в [domain_quality.md](../checklists/domain_quality.md).
