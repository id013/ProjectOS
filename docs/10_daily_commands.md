# Ежедневные команды

Каждый блок готов к копированию в ChatGPT Work.

## Начать рабочую сессию

```text
Начни рабочую сессию Project OS. Прочитай Project Status, Project DNA, активные решения,
риски и последний Handoff Pack. Покажи: цель сессии, минимальный Context Manifest,
одно ближайшее действие, критерии готовности и действия, требующие моего утверждения.
Не начинай несвязанные задачи.
```

## Проверить состояние проекта

```text
Проверь состояние проекта по реестрам, а не по памяти чатов. Дай сводку: этапы,
владельцы, блокеры, просрочки, C2/C3 риски, устаревшие зависимости, незакрытые решения
и одно рекомендуемое следующее действие. Отметь расхождения между документами.
```

## Подготовить новый этап

```text
Подготовь следующий этап: цель, границы, входы, SoT, зависимости, риски, выход,
Definition of Done, Quality Gate, владелец и Context Manifest. Не начинай выполнение.
```

## Создать новую Work-задачу

```text
Определи, нужна ли отдельная Work-задача. Если да, сформируй готовый стартовый блок:
одна цель, область и исключения, входы, SoT, ограничения, запрещенные действия,
ожидаемый артефакт, критерии готовности, порядок QA и место фиксации результата.
Если нет — кратко объясни, почему безопасно продолжить текущую.
```

## Закрыть текущий этап

```text
Закрой этап по протоколу Project OS: проверь DoD, создай итоговый артефакт, обнови
решения/риски/допущения/реестры, перечисли stale-зависимости, подготовь Handoff Pack
и выдай вердикт CLOSED / CLOSED WITH ACCEPTED RISK / NOT CLOSED.
```

## Зафиксировать утвержденную версию

```text
Подготовь фиксацию Approved-версии: имя файла, номер, дату, владельца, критерии приемки,
источники, changelog, заменяемую версию и список зависимостей. Не утверждай за человека;
покажи финальный approval-блок.
```

## Обновить источник истины

```text
Обнови выбранный источник истины только после проверки полномочий и версии. Создай
Decision Log, change impact list, пометь старую версию Superseded и обнови либо явно
пометь stale все зависимые артефакты. Покажи, что осталось непроверенным.
```

## Проверить противоречия

```text
Проведи conflict scan: дубли назначения, версии правил, термины, цены, условия,
неподтвержденные услуги, даты, владельцы и зависимости. Не усредняй конфликтующие факты.
Заполни таблицу конфликтов, критичность, временное правило и маршрут разрешения.
```

## Проверить, что забыто

```text
Сопоставь Charter, план, DoD, Decision/Assumption/Risk Logs, Artifact и Chat Registries.
Найди обещанные, но не созданные выходы; решения вне SoT; просроченные допущения;
чаты без итога; артефакты без владельца; устаревшие зависимости. Отсортируй по риску.
```

## Подготовить передачу контекста

```text
Создай Handoff Pack для [получатель/платформа/этап]. Включи только необходимый контекст:
статус, утвержденные решения, SoT, что читать/не читать, риски, открытые вопросы,
следующее действие, DoD и запреты. Удали секреты и пометь непереносимые допущения.
```

## Провести аудит проекта

```text
Проведи независимый аудит Project OS. Проверь governance, источники, версии, контекст,
решения, конфликты, QA, безопасность, зависимости, закрытие этапов и переносимость.
Выдай находки C3/C2/C1/C0, доказательства, владельцев, сроки и итоговый verdict.
```

## Провести ретроспективу

```text
Проведи ретроспективу на фактах из журналов. Найди трение, потери контекста, ошибки,
лишние действия и причины. Предложи изменения Project OS только при повторяемой проблеме
и измеримой пользе; для каждого дай риск бюрократии, тест, метрику и rollback.
```

## Предложить автоматизации

```text
Найди повторяемые действия с четким входом/выходом. Для каждого оцени частоту, время,
риск, зрелость правил, нужные права, логирование, идемпотентность, approval и fallback.
Рекомендуй минимальный уровень автоматизации; не включай ее автоматически.
```

## Архивировать завершенный этап

```text
Подготовь архив этапа: убедись, что результат Approved, реестры и Handoff обновлены,
активные ссылки ведут на замену, секреты не дублируются, а рабочий контекст очищен.
Перемести/пометь только перечисленные артефакты и создай архивный manifest.
```
