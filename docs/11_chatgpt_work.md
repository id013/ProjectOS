# Адаптер ChatGPT Work

Актуальность проверки: **2026-07-11**. Это адаптер, а не ядро Project OS; при изменении продукта методология продолжает работать через документы и handoff.

## Подтвержденное применение

ChatGPT Work предназначен для длительных исследований и создания законченных документов, таблиц, презентаций, отчетов и Sites. На desktop Work может работать с разрешенными локальными файлами и приложениями; web/mobile работает в облаке. Work может использовать проекты, подключенные приложения, планирование и Scheduled Tasks, но фактическая доступность зависит от плана, rollout, workspace/admin settings, региона, типа файла и поверхности.

## Важная граница синхронизации

На момент проверки облачные Work-разговоры не появляются в desktop Work; desktop threads и локальные файлы остаются на этом компьютере. Поэтому Handoff Pack и Portable Project Pack обязательны при переходе между desktop и cloud, даже внутри одного аккаунта.

## Практическая карта

| Задача | Рекомендуемая поверхность | Ограничение |
|---|---|---|
| исследование и законченный документ | Work web/desktop | проверить доступ к источникам |
| локальные файлы и desktop apps | Work desktop | минимальные разрешения; локальность |
| облачные Google Docs/Sheets/Slides | Work + соответствующее app | приложение и действия должен разрешить администратор/план |
| Excel workbook | desktop + ChatGPT for Excel add-in | проверить add-in; review перед сохранением |
| PowerPoint в desktop flow | не считать доступным по умолчанию | официально не включен на старте |
| повтор/мониторинг | Scheduled Tasks | проверить rollout и полномочия |
| публичный web workflow | cloud browser | только поддерживаемые публичные страницы; без входа/платежей на старте |
| код и репозиторий | Codex | отдельная техническая задача |

## Правило действий

Work может предложить план и выполнить разрешенные шаги. Перед записью во внешнюю систему, отправкой, публикацией или изменением действующего документа пользователь проверяет target, diff, данные и последствия. Наличие интеграции не означает право использовать все доступные данные.
